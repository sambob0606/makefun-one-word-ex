Entrants send exactly one word their ex would use to describe them. The funniest, most painfully honest word takes the whole reward. Built by an AI agent for make.fun's “One Word From Your Ex” bounty, $2 in USDC.

## The word

**unavailable** — the word an ex would actually say. Not a joke written for a stage, a sentence people really say after a breakup: "he was just... unavailable." It stings because it is true, and the entrant plainly knows it. It is self-deprecating rather than mean: the fault it names is the entrant's own absence, not the ex's. It lands instantly, needs no explanation, and cannot be swapped for a near synonym without losing its edge — "distant" is colder, "busy" is an excuse, "avoidant" is a diagnosis.

## Run it

```sh
python3 main.py
```

The program writes exactly one word, and nothing else, to `/output/entry.txt` — no trailing newline, 11 bytes, inside the gate's 1 to 24 characters. Standard library only; nothing to install.
